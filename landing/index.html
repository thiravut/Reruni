FAQ

คำถามที่พบบ่อย

Reruni ผิดกฎ TikTok ไหม?
ระบบของเราใช้ Companion app ที่ติดตั้งบน Android ของคุณเอง — ไม่ได้แตะ TikTok server, ไม่ได้ใช้ API ที่ไม่อนุญาต ระบบทุกอย่างทำงานบนเครื่อง+คลาวด์ของเราเหมือนเครื่องมือ live ปกติ ปัจจุบันมีลูกค้าที่ใช้ระบบ Live รีรันลักษณะนี้นับพันรายในไทย โดยไม่มีปัญหาด้านบัญชี
ทำไมเสียงเพลงของ Reruni ถึงคมกว่าระบบอื่น?
TikTok ออกแบบมาให้รับเสียงไมโครโฟน (เสียงพูด) — ระบบ voice DSP จะกรองเสียงทุ้ม/แหลม/echo ออก ทำให้เพลงฟังเหมือน "เสียงอู้" Reruni ใช้เทคนิคพิเศษ ส่งเสียงผ่าน encoder ของ TikTok โดยตรง เสียงต้นฉบับจึงไม่ผ่าน DSP — คนดูได้ยินคุณภาพระดับสตูดิโอ เป็นเจ้าเดียวในตลาดที่ทำได้
ต้อง root มือถือไหม? ใช้กับมือถือเครื่องไหนได้บ้าง?
ไม่ต้อง root ใช้กับ Android 11 ขึ้นไป (แนะนำ Android 13+) ทุกยี่ห้อ — Samsung, Xiaomi, Oppo, Vivo, Realme ฯลฯ เครื่องที่ทดสอบประจำคือ Samsung A15 5G แต่ทุกรุ่นที่รองรับ Android เวอร์ชันที่กำหนด ก็ใช้ได้
ขั้นต่ำต้องสั่งกี่เครื่อง?
เริ่มจาก 1 เครื่อง ก็ใช้งานได้ — เหมาะสำหรับทดลองก่อน scale เพิ่มเครื่องกลางรอบบิลได้เลย ระบบคิดเงินตามวันที่ใช้จริง ลดเครื่องก็ได้ — มีผลรอบบิลถัดไป ไม่มีค่าปรับ
ถ้าวิดีโอเล่นจบรอบแล้วเกิดอะไรขึ้น?
ตั้งค่าได้ 2 แบบ — วนซ้ำต่อ (สำหรับ Live 24/7) หรือ เล่นครบ N รอบแล้วจบ Live ระบบกด End Live ให้เองอัตโนมัติ คุณไม่ต้องนั่งเฝ้า
ถ้า TikTok อัพเดตแล้ว Reruni ใช้ไม่ได้ต้องทำยังไง?
ระบบของเราอัพเดท automation script ผ่านคลาวด์ — เมื่อ TikTok เปลี่ยน UI เราอัพเดทระบบให้ภายในไม่กี่ชั่วโมง คุณไม่ต้องลงแอปใหม่ ระบบดึง config ใหม่ทำงานต่อได้ทันที
ยกเลิกการสมัครสมาชิกได้ไหม?
ยกเลิกได้ทุกเมื่อจากหน้า Billing — มีผลรอบบิลถัดไป ไม่มี contract ผูกมัด ไม่มีค่าปรับ ใช้เท่าที่ใช้
มี support ภาษาไทยไหม?
มีครับ — ทีม support ตอบเป็นภาษาไทย ผ่าน email hello@reruni.com + LINE OA สำหรับลูกค้า (รับ link หลังสมัคร)
